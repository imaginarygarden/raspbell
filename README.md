# `Raspbell`

Raspbell is an open-source smart doorbell firmware for embedded Linux-capable boards and a cross-platform application for remote control over the firmware functionalities. The main goal is to provide a reusable foundation where configurations for separate boards can be added over time as the project grows.

> [!WARNING]
> Raspbell is currently in early alpha. Features, APIs and firmware configuration
> may change and bugs should be expected.
